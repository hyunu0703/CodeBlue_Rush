# CodeBlueRush Map Asset Production Guide

## 1. 문서 목적

이 문서는 CodeBlueRush의 최종 게임플레이 도시를 Unity에서 재구성하기 위해 필요한 맵 Asset 목록과 제작 범위를 정의한다.

이 문서는 **무엇을 제작해야 하는가**를 정의한다.

세부적인 시각 스타일, 이미지 규격, Unity Import 규칙은 다음 문서를 따른다.

`Md/CodeBlueRush_MapAssetStyleGuide.md`

---

# 2. Master Reference

모든 맵 Asset은 다음 이미지를 최종 시각 기준으로 사용한다.

`Assets/Images/Maps/Reference/CodeBlueRush_Map_MasterReference.png`

Master Reference는 CodeBlueRush 전체 도시의 다음 요소를 결정하는 최우선 시각 기준이다.

- 전체적인 색상
- 로우폴리 면 표현
- 명암
- 광원
- 그림자
- 카메라 시점
- 건물 형태와 비율
- 도로 표현
- 차량 비율
- 나무와 식생 형태
- 물과 암석 표현
- 도시 밀도
- 공간 배치 분위기

이미지 생성 전 반드시 Master Reference를 직접 확인한다.

문서의 시각적 설명과 Master Reference가 충돌하는 경우:

**Master Reference의 실제 표현을 우선한다.**

단:

- Unity 기술 규격
- 기존 게임 시스템 규칙
- 기존 Road Prefab 규격
- 기존 City Generator 구조

와 충돌하는 경우에는 기존 프로젝트 구조를 우선한다.

Master Reference 자체는 게임에 직접 사용하는 최종 맵 이미지가 아니라
모든 Asset 제작을 위한 **시각 기준 이미지**이다.

# 3. 공통 제작 기준

모든 카테고리에 공통으로 적용한다.

- 시점: 2D Top-Down / Near-Orthographic
- 스타일: 밝고 선명한 캐주얼 로우폴리
- 형태: 단순하고 명확한 실루엣
- 입체감: Master Reference 수준의 얕은 높이와 측면 표현 허용
- 명암: 큰 면 단위의 단순한 명암
- 광원: 모든 Asset에서 동일한 방향 유지
- 색상: Master Reference의 높은 채도와 밝은 색 대비 유지
- 독립 오브젝트: 투명 PNG
- Ground / Road / Water 등 바닥 Asset은 투명 배경 예외 허용
- Unity에서 각각 독립 Sprite로 사용할 수 있어야 한다
- 도로류는 타일처럼 정확하게 연결 가능해야 한다
- 건물류는 독립적으로 배치 가능해야 한다
- 소품류는 반복 배치 가능해야 한다
- 도시 내부 도로는 기본적으로 일반 지상도로로 제작한다
- 필요하지 않은 고가도로와 입체교차 구조는 추가하지 않는다

금지:

- 강한 Isometric 시점
- 3점 투시
- 강한 원근 왜곡
- 리소스마다 다른 카메라 각도
- 과도한 사실 표현
- PBR 스타일
- Pixel Art 스타일 혼합
- 서로 다른 Low Poly 스타일 혼합
- 불필요한 텍스트와 UI 포함

# 6. 카테고리 제작 방식

한 카테고리를 처음부터 대량 생성하지 않는다.

다음 순서를 따른다.

```text
Master Reference 확인
↓
Production Guide 확인
↓
Style Guide 확인
↓
기존 같은 종류 Asset 확인
↓
대표 Asset 1개 생성
↓
Unity에서 크기 / 스타일 테스트
↓
대표 Asset 확정
↓
Secondary Reference로 사용
↓
나머지 Variant 제작
```

예:

```text
Master Reference
+
Road_Straight_2Lane
↓
나머지 Road Asset 제작
```

또는:

```text
Master Reference
+
Tree_Medium_01
↓
나머지 Tree Asset 제작
```

```text
+
Nature

+

City Generator

```

각 Asset은 독립적으로 교체하거나 재사용할 수 있어야 한다.

를 각각 조립한다.

# 9. Asset 완료 조건

Asset은 다음 조건을 모두 만족해야 한다.

## Visual

- Master Reference와 같은 게임의 Asset처럼 보이는가
- 카메라 시점이 일치하는가
- 로우폴리 표현이 일치하는가
- 색상과 명암이 일치하는가
- 광원 방향이 일치하는가
- 비율이 다른 Asset과 어울리는가

## Technical

- 독립 Sprite로 사용할 수 있는가
- 필요한 경우 Transparent PNG인가
- 파일명 규칙에 맞는가
- 불필요한 배경이 없는가

## Road

도로라면 추가 확인한다.

- 다른 도로와 폭이 동일한가
- 연결 지점이 일치하는가
- 차선 중심이 일치하는가
- 중앙선이 이어지는가
- 횡단보도와 연결 가능한가
- 인도와 연결 가능한가

# 10. 최종 목표

CodeBlueRush Map Asset 제작의 최종 목표는:

**Master Reference에 보이는 도시의 분위기를 유지하면서,
Unity에서 독립 Asset을 조립하여 동일한 세계를 재구성하는 것**이다.

개별 Asset 하나의 완성도보다
전체 Asset을 함께 배치했을 때의 통일성을 우선한다.
