# 시민 AI

## 동작과 연결

- `GamePlay` 씬의 `MissionSystem`에 `RoadCitizenController`를 연결했다. `RoadTrafficController`가 시민과 차량을 같은 고정 스텝에서 순서대로 진행한다.
- 시민은 임시 사각형이며 활성 도로의 인도에 생성된다. 인도 분기에서는 이동 경로를 무작위로 선택하고 막다른 곳에서는 돌아선다.
- 도로 이미지의 차로 폭 84.6px, 인도 폭 64px, 횡단보도 중앙 위치를 기준으로 보행 경로를 구성한다. 2·4·6차선, 회전 배치, 혼합 T자와 십자 교차로를 지원한다. 닫힌 T자 방향은 횡단보도가 없는 인도로 연결한다.
- 보행 신호는 횡단 방향과 나란한 차량 **직진 녹색**에만 진행이다. 차량 황색과 좌회전 현시에는 새 횡단을 시작하지 않는다. 기존 차량 신호의 3초 녹색·1초 황색 주기는 유지한다.
- 신호가 녹색이어도 해당 횡단보도에 진입/진출하는 차량 예약이 남아 있으면 시민이 기다린다. 플레이어와 충돌 후 물리 제어 차량도 근접 관측으로 확인한다.
- 횡단을 시작한 시민은 적색으로 바뀌어도 끝까지 건넌다. 시민의 점유를 차량 판단 전에 등록하고 마지막 시민이 나가야 차단을 해제한다. 차량 AI는 진입·진출 횡단보도 중 하나라도 점유되면 정지선에서 기다린다.
- 후송 경로 확장에서는 기존 시민 위치와 횡단 상태를 유지한다. 새 미션, 도로 회수, 거리 이탈, 컴포넌트 비활성화에서는 해당 시민과 점유를 정리한다. 일시정지 중에는 생성과 이동을 진행하지 않는다.
- 보행 중에는 현재 사각형과 같은 크기의 `BoxCollider2D` 트리거와 `Kinematic Rigidbody2D`를 사용한다. 차량 충돌 뒤에는 아래의 쓰러짐·물리 규칙을 따른다.

## 쓰러짐과 물리 충돌

- 구급차 또는 `RoadTrafficCollision`을 가진 일반 차량과 처음 접촉하면 가로로 납작하게 눕힌다. 가로는 기존 1.35배를 유지하고, 세로는 기존 0.55배에서 **충돌 전 크기의 2/3배**로 키운다. 외형과 충돌 영역을 함께 바꾼다.
- 충돌 당시 시민의 색을 유지한 상태에서 **게임 시간 0.8초 동안** 진한 회색(`RGBA 0.2, 0.2, 0.2, 1`)으로 서서히 바꾼다. 재충돌은 진행 중 색 전환을 다시 시작하지 않는다. 일시정지 중에는 색 전환도 멈추며, 비활성화·풀 재사용 시 이전 전환을 취소하고 새 시민의 색을 복구한다.
- `Citizen.IsFallen`을 유지하고 보행 속도·횡단 허가를 제거한다. 이후 신호나 인도 경로를 따라 이동하거나 자동으로 일어서지 않는다.
- 충돌 즉시 `Dynamic Rigidbody2D`와 비트리거 콜라이더로 전환한다. 최초 접촉은 차량과 시민의 상대 속도·질량에 따른 충격을 전달하고, 이후 재충돌은 Unity 2D 엔진이 처리한다. 구급차뿐 아니라 Kinematic AI 차량도 시민을 튕겨낼 수 있다.
- 탑뷰 XY 평면에서 충격 방향으로 튕겨 나가 회전하고, 선형·각 감쇠로 멈춘다. 게임용 기본값은 시민 질량 70kg, 선형·각 감쇠 3, 최초 충격 반발 비율 0.15, `gravityScale = 0`이다. 실측 인체 충돌 모델을 뜻하는 값은 아니다.
- 물리 전환 뒤에는 보행 시뮬레이션이나 `MovePosition`으로 위치를 덮어쓰지 않는다. 시민 위치는 실제 물리 차체에서 읽고, 기존 경로의 도로가 반환되어도 주변에 있는 쓰러진 시민은 유지한다. 거리 이탈·맵 교체 시에는 기존 수명 정책으로 회수한다.
- 쓰러진 시민은 보행 횡단 점유에서 제외하고 실제 콜라이더로 차량·건물 접촉에 반응한다. 다른 차량에 먼저 치인 시민도 이후 구급차와 접촉하면 기존 시민 실적 규칙으로 기록한다. 같은 시민의 중복 감점은 없다.
- 풀에서 새 시민으로 재사용할 때 자세·색·회전·속도·물리 모드·트리거를 초기화한다. 런타임 생성 경로에서 자동 연결하므로 추가 패키지나 수동 Inspector 연결은 필요 없다.

### 쓰러짐·물리 검증

Unity **6000.3.23f1**, Windows Editor 배치 모드, Test Framework **1.6.0**, URP **17.3.0**에서 같은 프로젝트의 임시 복사본으로 검증했다.

- 시민 점수 10개, 실제 물리 접촉·색 전환 9개, GamePlay 인계·UI 1개, 기존 인계 결과 17개로 **37개 테스트 통과**, C# 컴파일 오류 없음.
- 크기·색 연출 조정에서는 가로 1.35배·세로 2/3배, 충돌 직후 원래 색 유지, 0.4초 중간색·0.8초 최종 회색을 확인했다. 실제 프레임의 일시정지·복귀 후 완료, 재충돌 시 전환 유지, 풀 재사용 후 이전 색 전환이 적용되지 않는 것도 확인했다.
- 2500kg 구급차와 70kg 시민의 6유닛/초 충돌에서 진한 회색·납작한 자세·Dynamic 전환·실제 위치 이동을 확인했다. 10초 물리 진행 후 속도 0.03유닛/초 미만과 보행 미복귀를 확인했다.
- 실제 AI 주행과 같은 Kinematic `MovePosition` 차량으로 시민의 물리 이동과 구급차 감점 없음, 쓰러진 시민 재충돌 시 추가 이동과 같은 시민 중복 감점 방지, 풀 재사용의 보행 모드·트리거·속도·자세 초기화를 확인했다.
- GamePlay 시드 24646948에서 실제 시민 접촉부터 병원 인계까지 HP 100%·시민 1명 결과 95점을 유지하고 640×480에서 결과 텍스트 넘침 없음을 확인했다. 그래픽 출력 없는 검증이므로 실제 화면에서의 연출·다른 해상도·빌드는 미검증이다.

화면 확인 순서: GamePlay에서 미션을 수락하고 구급차로 사각형 시민을 친다. 세로 2/3 크기의 납작한 모습으로 튕겨 나가면서 원래 색에서 0.8초 동안 서서히 진한 회색이 되어야 한다. 회전한 뒤 멈추고, 신호가 바뀌어도 보행을 재개하지 않아야 한다. 같은 시민을 다시 밀면 물리적으로 이동하되 실적 인원은 늘지 않아야 한다. 일반 AI 차량의 충돌도 시민을 쓰러뜨리지만 구급차가 접촉하기 전에는 시민 감점에 포함되지 않아야 한다.

## 시민 충돌과 실적

2026-10-28 확정: **시민 한 명당 5점 감점**, 시민 충돌이 있으면 **무사고 보너스 30점 취소**.

- 출동부터 병원 인계까지 `MissionPerformance.IsRecording`인 동안만 기록한다. 미션 전·종료 후·일시정지 중에는 추가하지 않는다.
- 시민의 시뮬레이션 객체를 식별자로 사용한다. 같은 시민과 지속 접촉하거나 다시 접촉해도 한 미션에서는 한 명으로 집계한다. 동일한 사각형 외형을 풀에서 꺼내 새 시민에게 사용하면 다른 시민으로 집계한다.
- 일반 AI 차량과의 접촉은 제외한다. 시민 충돌은 기존 저속·고속 차량 충돌 횟수에 중복으로 더하지 않는다.
- 차량·시민 충돌이 모두 없고 환자가 생존한 경우에만 보너스를 지급한다. 기존 반올림, 실적 하한 0, 사망 시 0점 규칙을 유지한다.
- 결과 화면에 시민 충돌 인원, 직접 감점과 무사고 보너스 취소를 표시하고, 차감된 당일 실적을 기존 누적·저장 후보에 반영한다. 결과 확인 전에 원본 진행 상태를 수정하지 않는다.
- 예: HP 100%, 차량 충돌 0회에서 시민 0명이면 130점, 1명이면 95점, 2명이면 90점이다.
- 시민 콜라이더와 `RoadCitizenCollision`은 기존 런타임 생성·풀 재사용 경로에서 자동 연결한다. 씬이나 Inspector에 추가 수동 연결은 필요 없다.

기존 기획 문서의 차량 감점 2·10점/40km/h와 현재 구현의 1·3점/60km/h 사이에는 이번 변경 이전부터 차이가 있다. 이번 작업에서는 현재 차량 동작을 유지하고 시민 규칙만 추가했다.

### 시민 감점 도입 단계의 검증 결과

- Unity **6000.3.23f1**, Windows Editor 배치 모드, Test Framework **1.6.0**, URP **17.3.0**에서 원본과 같은 Assets·Packages·ProjectSettings의 임시 복사본으로 검증했다.
- `CitizenScoreTests` **10개**, `CitizenCollisionTests` **4개**, `CitizenCollisionSceneTests` **1개**, 기존 `MissionResultTests` **17개**, 합계 **32개 통과**. C# 컴파일 오류도 없었다.
- 실제 격리 2D 물리 월드에서 6유닛/초 접촉, 지속 접촉·재접촉 중복 방지, 같은 외형을 새 시민에게 재사용한 경우의 별도 집계, 미션 전·후 제외와 다음 미션 초기화, 구급차 외 차량 제외를 확인했다.
- GamePlay 시드 **24646948**, 현재 사각형의 XY 크기와 같은 트리거에서 구급차 접촉 1명을 기록하고 실제 `MissionController.CompleteMission`으로 HP 100% 결과 **95점**, 누적 후보 **95점**을 확인했다. 결과 UI의 시민 1명·감점 5점·무사고 보너스 취소 표시와 **640×480**에서 텍스트 영역 넘침 없음을 확인했다.
- 새 미션과 시민 콜라이더는 자동 연결되어 수동 설정은 필요 없다. 빌드와 실제 화면 출력·다른 해상도의 UI는 미검증이다.

화면 수동 확인: GamePlay에서 미션을 수락하고 구급차로 사각형 시민 한 명과 접촉한다. 같은 시민과 계속 접촉하거나 재접촉해도 결과의 시민 수가 한 명으로 유지되어야 한다. 다른 시민과 접촉하면 인원이 증가해야 한다. 병원 인계 후 시민 인원×5점과 보너스 취소가 반영된 점수를 확인하고, 결과 확인 뒤 다음 날 누적 실적에 같은 점수가 반영되는지 확인한다.

## 검증

2026-10-28, Unity **6000.3.23f1**, Windows Editor 배치 모드(`-nographics`), URP **17.3.0**, Test Framework **1.6.0**에서 프로젝트 복사본으로 검증했다. 원본 프로젝트를 사용 중인 Editor는 종료하지 않았다. 패키지와 프로젝트 설정은 변경하지 않았다.

| 완료 조건 | 구현 | 실제 검증 |
| --- | --- | --- |
| 시민이 인도를 돌아다님 | 완료 | 도로 경계 연결·회전·혼합 T자 경로 및 GamePlay 시민 생성 확인 |
| 직진 녹색과 연동하여 횡단하고 신호 변경 후에도 끝까지 이동 | 완료 | 적색·황색 대기, 횡단 도중 적색 전환 후 이동·완료 확인 |
| 횡단 중 차량 양보 | 완료 | 기존 차량 예약 대기, 복수 시민 점유, 실제 차량 시뮬레이터의 정지선 대기·해제 후 재출발 확인 |

- 시민 테스트 **14개**, 기존 신호 테스트 **22개**, 합계 **36개 통과**.
- 전체 테스트 **132개 중 123개 통과**, 기존 차량 질량 테스트 **9개 실패**. 신규 시민 소스와 씬 연결을 제외하고 변경 전 `RoadTrafficController`·`RoadTrafficSignals`·`GamePlay`를 적용한 복사본에서도 같은 9개 실패를 재현했다. 기대 질량과 실제 질량의 차이이며 이번 작업에서는 수정하지 않았다.
- GamePlay Play Mode 검증 시드: 픽업 **24646948**, 후송 **57196741**. 초기 시민 **21명** 생성, 일시정지, 후송 확장 시 기존 시민 보존, 비활성화 시 외형·상태 정리와 재활성화 후 생성까지 확인했다.
- C# 컴파일과 관련 테스트는 통과했으며 빌드와 실제 화면 출력·가독성은 미검증이다.

`CitizenAITests`는 보행 녹색·황색 대기, 회전 도로 경계 연결, 혼합 T자 닫힌 방향, 적색 전환 후 횡단 완료, 복수 시민 점유, 차량 예약과 외부 차량 대기, 실제 차량 정지·재출발, 후송 확장 및 차단 소유권을 검증한다.

`CitizenSceneTests`는 저장된 GamePlay 씬에서 실제 Play Mode에 진입하여 시민 생성, 일시정지, 후송 확장과 위치 보존, 비활성화 정리 및 재활성화를 검증한다.

화면 수동 확인 순서:

1. Unity 6000.3.23f1에서 `GamePlay`를 실행하고 미션을 수락한다. 주변 인도에 색상이 다른 사각형이 생성되어 이동해야 한다.
2. 교차로에서 시민을 관찰한다. 직진 신호와 나란한 횡단보도에서 횡단하고, 적색으로 바뀌어도 차도 중간에 멈추지 않아야 한다.
3. 시민이 횡단 중일 때 관련 차량은 정지선에서 기다리고 마지막 시민이 보도에 도착하면 진행 가능한 신호에 따라 출발해야 한다.
4. 서로 다른 시드와 후송 확장에서 회전된 T자·십자 교차로를 확인한다. 시민이 인도와 횡단보도를 따라 이동하고 건물이나 차도 지름길로 이동하지 않아야 한다.

배치 검증은 그래픽 출력 없이 실행하므로 화면 배치와 가독성의 최종 확인은 위 순서로 수행한다.
