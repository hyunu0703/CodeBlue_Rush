# 시민 AI

## 동작과 연결

- `GamePlay` 씬의 `MissionSystem`에 `RoadCitizenController`를 연결했다. `RoadTrafficController`가 시민과 차량을 같은 고정 스텝에서 순서대로 진행한다.
- 시민은 임시 사각형이며 활성 도로의 인도에 생성된다. 인도 분기에서는 이동 경로를 무작위로 선택하고 막다른 곳에서는 돌아선다.
- 도로 이미지의 차로 폭 84.6px, 인도 폭 64px, 횡단보도 중앙 위치를 기준으로 보행 경로를 구성한다. 2·4·6차선, 회전 배치, 혼합 T자와 십자 교차로를 지원한다. 닫힌 T자 방향은 횡단보도가 없는 인도로 연결한다.
- 보행 신호는 횡단 방향과 나란한 차량 **직진 녹색**에만 진행이다. 차량 황색과 좌회전 현시에는 새 횡단을 시작하지 않는다. 기존 차량 신호의 3초 녹색·1초 황색 주기는 유지한다.
- 신호가 녹색이어도 해당 횡단보도에 진입/진출하는 차량 예약이 남아 있으면 시민이 기다린다. 플레이어와 충돌 후 물리 제어 차량도 근접 관측으로 확인한다.
- 횡단을 시작한 시민은 적색으로 바뀌어도 끝까지 건넌다. 시민의 점유를 차량 판단 전에 등록하고 마지막 시민이 나가야 차단을 해제한다. 차량 AI는 진입·진출 횡단보도 중 하나라도 점유되면 정지선에서 기다린다.
- 후송 경로 확장에서는 기존 시민 위치와 횡단 상태를 유지한다. 새 미션, 도로 회수, 거리 이탈, 컴포넌트 비활성화에서는 해당 시민과 점유를 정리한다. 일시정지 중에는 생성과 이동을 진행하지 않는다.
- 시민 외형에는 물리 콜라이더가 없으며 시민 간 회피·충돌 피해·사고 점수는 구현 범위에 포함하지 않는다. 플레이어 차량의 조작을 강제로 멈추지는 않는다.

## 검증

2026-10-28, Unity **6000.3.23f1**, Windows Editor 배치 모드(`-nographics`), URP **17.3.0**, Test Framework **1.6.0**에서 프로젝트 복사본으로 검증했다. 원본 프로젝트를 사용 중인 Editor는 종료하지 않았다. 패키지와 프로젝트 설정은 변경하지 않았다.

| 완료 조건 | 구현 | 실제 검증 |
| --- | --- | --- |
| 시민이 인도를 돌아다님 | 완료 | 도로 경계 연결·회전·혼합 T자 경로 및 GamePlay 시민 생성 확인 |
| 직진 녹색과 연동하여 횡단하고 신호 변경 후에도 끝까지 이동 | 완료 | 적색·황색 대기, 횡단 도중 적색 전환 후 이동·완료 확인 |
| 횡단 중 차량 양보 | 완료 | 기존 차량 예약 대기, 복수 시민 점유, 실제 차량 시뮬레이터의 정지선 대기·해제 후 재출발 확인 |

- 시민 테스트 **14개**, 기존 신호 테스트 **22개**, 합계 **36개 통과**.
- 전체 테스트 **132개 중 123개 통과**, 기존 차량 질량 테스트 **9개 실패**. 신규 시민 소스와 씬 연결을 제외하고 변경 전 `RoadTrafficController`·`RoadTrafficSignals`·`GamePlay`를 적용한 복사본에서도 같은 9개 실패를 재현했다. 기대 질량과 실제 질량의 차이이며 이번 작업에서는 수정하지 않았다.
- GamePlay Play Mode 검증 시드: 픽업 **24646948**, 후송 **57196741**. 초기 시민 **21명** 생성, 일시정지, 후송 확장 시 기존 시민 보존, 비활성화 시 외형·상태 정리와 재활성화 후 생성까지 확인했다.
- C# 컴파일과 관련 테스트는 통과했으며 빌드와 실제 화면 출력·가독성은 미검증이다.

`CitizenAITests`는 보행 녹색·황색 대기, 회전 도로 경계 연결, 혼합 T자 닫힌 방향, 적색 전환 후 횡단 완료, 복수 시민 점유, 차량 예약과 외부 차량 대기, 실제 차량 정지·재출발, 후송 확장 및 차단 소유권을 검증한다.

`CitizenSceneTests`는 저장된 GamePlay 씬에서 실제 Play Mode에 진입하여 시민 생성, 일시정지, 후송 확장과 위치 보존, 비활성화 정리 및 재활성화를 검증한다.

화면 수동 확인 순서:

1. Unity 6000.3.23f1에서 `GamePlay`를 실행하고 미션을 수락한다. 주변 인도에 색상이 다른 사각형이 생성되어 이동해야 한다.
2. 교차로에서 시민을 관찰한다. 직진 신호와 나란한 횡단보도에서 횡단하고, 적색으로 바뀌어도 차도 중간에 멈추지 않아야 한다.
3. 시민이 횡단 중일 때 관련 차량은 정지선에서 기다리고 마지막 시민이 보도에 도착하면 진행 가능한 신호에 따라 출발해야 한다.
4. 서로 다른 시드와 후송 확장에서 회전된 T자·십자 교차로를 확인한다. 시민이 인도와 횡단보도를 따라 이동하고 건물이나 차도 지름길로 이동하지 않아야 한다.

배치 검증은 그래픽 출력 없이 실행하므로 화면 배치와 가독성의 최종 확인은 위 순서로 수행한다.

## 주요 파일

- `Assets/Scripts/Traffic/RoadSidewalkNetwork.cs`: 도로 이미지 규격을 이용한 인도·횡단보도 연결.
- `Assets/Scripts/Traffic/RoadCitizenSimulation.cs`: 배회·신호 대기·횡단과 공동 점유.
- `Assets/Scripts/Traffic/RoadCitizenController.cs`: 사각형 외형, 주변 생성·회수와 맵 수명 연결.
- `Assets/Scripts/Traffic/RoadTrafficSignals.cs`, `RoadTrafficController.cs`: 보행 신호와 차량 고정 스텝 연동.
- `Assets/Scenes/GamePlay.unity`: `MissionSystem`에 시민 컴포넌트와 기본값 저장.
- `Assets/Scripts/Editor/CitizenAITests.cs`, `CitizenSceneTests.cs`: 상태·차량·실제 씬 검증.
