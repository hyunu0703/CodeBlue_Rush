# 차량 AI 및 코드 신호

현재 차로 그래프(`RoadLaneNetwork`) 위에서 AI 차량이 주행하도록 구현했다. 신호 외형은 생성하지 않는다. **GamePlay 씬 연결과 실제 Unity Play Mode 검증은 아직 실행하지 않았다.**

## 실행 방법

1. Unity `6000.3.23f1`에서 새 스크립트 import/컴파일이 끝날 때까지 기다린다.
2. `Assets/Scenes/GamePlay.unity`를 연다.
3. `Tools > CodeBlue > Setup GamePlay Traffic AI`를 실행한다.
4. `MissionSystem`의 `RoadTrafficController`를 확인하고 씬을 저장한다. 기존 설정이 있으면 메뉴는 선택만 하고 덮어쓰지 않는다.
5. Play Mode에서 미션을 수락한다. 맵이 생성되면 차량이 분산 배치되고 이후 맵 바깥 경계에서 진입한다.

설정 메뉴는 기존 `MissionMapGenerator`, `Ambulance`의 Rigidbody2D 및 `Assets/Prefabs/Car/`의 구급차/PCX를 제외한 자동차 외형 프리팹 9개만 연결한다. PCX가 이전 씬의 목록에 남아 있어도 런타임 생성 후보에서 제외한다. 기존 컨트롤러에 설정 메뉴를 다시 실행하면 PCX 참조만 제거하고 다른 튜닝은 보존한다. 씬을 자동 저장하거나 원본 차량 프리팹을 수정하지 않는다. Undo 가능하다. 기존 물리/제어 스크립트가 있는 외형 프리팹은 거부한다.

새 파일의 `.meta`는 이 작업에서 만들지 않았다. Unity가 다음 스크립트 5개 및 새 폴더의 메타데이터를 생성해야 한다.

- `Assets/Scripts/Traffic/RoadTrafficSignals.cs`
- `Assets/Scripts/Traffic/RoadTrafficVehicle.cs`
- `Assets/Scripts/Traffic/RoadTrafficSimulation.cs`
- `Assets/Scripts/Traffic/RoadTrafficController.cs`
- `Assets/Scripts/Editor/GamePlayTrafficSetup.cs`

## 신호와 한국 교통 규칙

[도로교통법 시행규칙 별표 2](https://www.law.go.kr/LSW/flDownload.do?bylClsCd=110201&flSeq=152754991&gubun=)와 [정부의 우회전 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148911138)를 참고했다. 실제 특정 교차로의 현시를 복제한 것은 아니다. 게임용 현시는 각 단계 5초로 다음과 같이 구성했다.

| 단계 | 신호 | 시간 |
| --- | --- | --- |
| 1 | 남북 직진 | 5초 |
| 2 | 남북 직진 황색 | 5초 |
| 3 | 남북 보호 좌회전 | 5초 |
| 4 | 남북 좌회전 황색 | 5초 |
| 5 | 동서 직진 | 5초 |
| 6 | 동서 직진 황색 | 5초 |
| 7 | 동서 보호 좌회전 | 5초 |
| 8 | 동서 좌회전 황색 | 5초 |

전체 주기는 40초다. 교차로마다 시작 위상이 다르다. 비보호 좌회전이나 유턴은 추가하지 않는다. 황색 직진/좌회전에는 새로 진입하지 않는다. 차체가 이미 진입한 차량은 교차로를 빠져나간다.

기본 우회전은 일반 원형 신호의 의미를 따른다. 적색에서는 정지선 앞에 완전히 멈춘 상태를 0.3초 확인한 뒤 다른 차량에 양보한다. 이 0.3초는 법정 대기 시간이 아니라 게임에서 일시정지를 확인하는 구현 값이다. 일반 녹색/황색에서도 보행자와 다른 차량에 양보한다. `Simulation.Signals.SetDedicatedRightSignal(roadOrdinal, true)`를 호출한 교차로는 전용 우회전 녹색 현시에서만 진입한다.

`SetCrossingBlocked(roadOrdinal, side, true/false)`는 향후 보행자 시스템이 횡단 중이거나 횡단하려는 보행자를 보호하도록 연동하는 API다. 현재 이동하는 보행자와 보행자 신호는 구현 범위에 포함하지 않았다.

교차로 경로의 예약은 신호 허가와 별개로 적용한다. 뒷범퍼가 빠져나갈 때까지 충돌/합류 경로의 진입을 막는다. 전용 신호의 허가를 받아도 충돌 차량이나 출구 정체가 있으면 기다린다.

## 주행과 안전거리

- 기존 차로 연결에서 진행 경로를 한 번 선택하고 정차 중에도 유지한다. 직진/좌회전/우회전은 해당 차로가 허용하는 경로에서만 선택한다.
- AI 차량은 생성된 Kinematic Rigidbody2D로 `FixedUpdate`의 `MovePosition/MoveRotation`을 사용한다. 기존 Dynamic 플레이어 제어는 유지한다.
- 앞차와 플레이어의 위치, 속도, 길이/폭을 현재 및 다음 경로에 투영하여 감속한다. 최소 간격은 차로 폭의 0.6배, 목표 시간 간격은 1.4초다. 거리 단위는 맵 로컬 유닛이며 미터로 가정하지 않는다.
- 플레이어와 외부 콜라이더의 크기는 회전한 월드 AABB를 감싸는 정사각형으로 보수적으로 관측한다. 옆차선의 이동 차량은 0.8초 뒤 예상 위치도 검사한다.
- AI가 차로를 바꾸는 동안 시작/목표 차로를 모두 점유한 것으로 관측한다. 변경은 약 2초, 재변경 간격은 최소 6초다. 앞뒤 간격/빠른 후방차/다른 변경 의도가 위험하면 시작하지 않는다.
- 느린 앞차가 있고 옆차로가 안전하면 자동으로 차로를 바꾼다. 신호 대기를 추월하려고 차로를 바꾸지는 않는다. 교차로 안과 정지선 근처에서도 새 변경을 시작하지 않는다.
- 교차로 출구에 차체 전체가 들어갈 여유가 없으면 진입하지 않는다. 연결이 끝나는 경계에서는 정차한 후 해당 AI 인스턴스를 제거한다.

`Maximum Vehicles` 기본값은 32이며 상한은 64다. `Spawn Interval` 기본값은 1초다. `Obstacle Layers`는 외부 Dynamic/Kinematic Rigidbody2D를 추가 감지하는 레이어다. 기본 전체 레이어에서도 바디가 없는 도로/장식 콜라이더, Static 바디, 트리거, 시뮬레이션을 끈 바디는 제외한다. 소유 AI 차체는 바디와 콜라이더 식별자 양쪽으로 중복 관측을 방지한다. 플레이어는 이 필터와 별개로 항상 관측하고 AI 차량끼리는 차선 데이터로 관측한다. 따라서 `Nothing`도 이 두 감지는 유지한다. 정적 환경 장애물을 감지하는 기능은 이 필터에 포함하지 않는다. 맵 부모는 양수 균일 XY 스케일과 Z축 회전을 사용해야 한다. 자동 2D 물리는 `FixedUpdate` 모드여야 한다.

비활성화와 새 미션/후송 맵 스냅숏 교체에서는 이 컴포넌트가 생성한 차량과 신호만 정리하고 새로 구성한다. 따라서 후송 맵이 추가될 때 기존 교통의 차량 위치와 신호 시간은 재시작된다. 일시정지에서는 진행하지 않는다. 변경 가능한 전역 static 상태나 외부 이벤트 구독은 추가하지 않았다.

## 검증

`output/traffic-ai-20261013/`의 .NET 검사 하네스는 실제 런타임 소스를 사용한다. Unity의 Vector2/참조 어셈블리를 사용하지만 네이티브 물리와 MonoBehaviour 생명주기는 실행하지 않는다. 신호 현시, 앞차/플레이어 정차 추종, 끼어들기 감속, 후방차가 있는 변경 거부, 적색 우회전 정지, 직진/좌회전 신호 대기, 출구 정체, 동시 예약, 차량 차체 분리, 일시정지/스냅숏 무효화를 검사한다. 실제 도로 프리팹 13종의 네 방향 회전 배치도 검사한다.

근사 컴파일은 생성 프로젝트의 참조를 출력 폴더 사본에서 사용한다. 원래 `.csproj`, 패키지 및 런타임 어셈블리 구성을 바꾸지 않았다. 런타임 어셈블리는 기존 `Assembly-CSharp`, 설정 메뉴는 `Assembly-CSharp-Editor`에 속한다. 기존 공개 API는 유지하고 `MissionMapGenerator.LaneMapRoot` 읽기 전용 프로퍼티만 추가했다.

최종 로직 검사 결과: 순수 로직 13개 시나리오/561,858개 판정 통과. 작은 고정 스텝에서도 출발 가속이 0으로 초기화되지 않는 검사를 추가했다. 목표 이동량은 한 번 계산한 float 값을 사용한다. 새 런타임 파일은 관련 기능의 기존 구조를 유지하기 위해 `Assets/Scripts/Traffic/`에 배치했다.

사용자가 Play Mode에서 `Obstacle Layers`를 `Everything`에서 `Nothing`으로 바꾸면 출발한다고 확인했다. 이 결과로 장애물 관측 경로가 정지 조건을 만든다는 것은 확인했으나, 실제 어떤 콜라이더가 차단했는지는 캡처하지 못했다. 이번 수정은 정적 환경 콜라이더 제외와 AI 차체 중복 제외를 적용한다. 수정 후 `Everything`에서의 실제 주행은 아직 에이전트가 확인하지 못했다.

**Unity 컴파일/import/테스트/플랫폼 빌드 미실행:** `AGENTS.md`의 `UNITY_PATH`가 `TODO`이며 사용자에게 Unity 탐색을 요청받지 않았기 때문이다. Standalone 백엔드는 여전히 알 수 없다. 확인된 설정은 Unity 6000.3.23f1, Input System 1, Domain Reload 비활성/Scene Reload 활성, 2D 자동 FixedUpdate 시뮬레이션이다.

아직 수행하지 않은 Play Mode 확인:

1. 미션 수락 후 실제 차량 외형/콜라이더 크기와 차선 중앙 정렬 확인.
2. 플레이어가 앞을 막거나 옆에서 끼어들 때 감속·정차·재출발 확인. 빠른 충돌이나 플레이어의 차량 들이받기까지 사고 방지를 보장하지 않는다.
3. 사거리/T자/혼합 차로 도로의 좌·우회전, 신호 대기, 출구 정체 확인.
4. 일시정지/재개, 컨트롤러 비활성화/재활성화, 후송 확장, 반복 Play 세션에서 차량 중복/잔존 여부 확인.
5. 32/64대 조건에서 Unity Profiler로 물리와 관측 쿼리 비용 확인. 성능 측정은 아직 실행하지 않았다.

AGENTS.md 제안: `UNITY_PATH`, 배치 타임아웃, 비동기 스타일의 TODO와 Standalone 백엔드 정보를 사람이 확인하여 갱신할 수 있다. 이번 작업에서는 AGENTS.md를 수정하지 않았다.
