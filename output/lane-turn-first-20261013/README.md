# 우회전 출구 차로 변경

Road_T_V6Lane_H4Lane의 남쪽 세로 진입 2차로 우회전은 동쪽 가로 출구 1차로로 연결한다. 이전 2차로 출구 연결을 대체한다. Road_T_6Lane의 2차로→2차로 우회전과 기존 바깥 차로의 우회전은 유지한다. 차로 번호는 중앙선 쪽부터 1이다.

런타임 레이아웃 생성 규칙을 변경했으며, Prefab 직렬화 값이나 메타데이터 변경은 없다. 기존에 생성된 그래프에는 새 맵 생성 또는 Play Mode 재시작 시 반영된다.

## 검증(Verification)

- 변경된 실제 런타임 소스와 13종 Prefab 데이터를 사용하는 .NET 검사: 165,805개 조건 통과, 156개 회전·경계 사례, 100개 픽업/후송 시드 쌍.
- 두 T자 도로의 네 회전에서 지정 출구 차로와 다음 일자 도로까지 경로 연결 확인. 혼합 폭 T자 도로의 기존 바깥 차로 우회전은 출구 2차로로 유지되어 별도 출발 경로에 연결됨을 확인.
- 이번 수정에 대한 Unity 네이티브 컴파일/Play Mode 실주행은 미실행. 작은 순수 경로 생성 규칙 변경을 기존 .NET 검사로 검증했다.
- 이전 검증 결과는 output/lane-turn-20261013에 보존했다.
